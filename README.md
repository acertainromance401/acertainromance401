### 1. [GAME — RIVAL](https://github.com/acertainromance401/GAME)

[![Repository](https://img.shields.io/badge/Source-GAME-181717?style=flat-square&logo=github)](https://github.com/acertainromance401/GAME)
[![Play](https://img.shields.io/badge/Play-Web_Build-00A86B?style=flat-square&logo=googlechrome&logoColor=white)](https://acertainromance401.github.io/GAME/)
![Swift](https://img.shields.io/badge/Swift-SceneKit-F05138?style=flat-square&logo=swift&logoColor=white)
![AI](https://img.shields.io/badge/AI-Adaptive_NPC-7B1FA2?style=flat-square)

플레이어의 반복 습관을 학습해 대응 방식을 바꾸는 AI 라이벌과 겨루는 3D 복싱 게임입니다. 현재 메인 앱은 **Swift 6 + SceneKit 기반 iPhone 가로형 게임**이며, 아이디어 검증부터 제품화까지 C++20 TUI, Python/Tkinter, 브라우저 빌드를 거쳐 발전시켰습니다.

- **Adaptive AI:** 8종 공격, 가드, 좌우 더킹, 백스텝, 압박·후퇴 비율과 반복 행동을 수집해 라운드별 대응 가중치를 생성합니다.
- **Combat System:** 공격별 피해량·사거리·스태미나 비용, 헛스윙 노출, 카운터, 반복 기술 약화, 탈진과 KO를 하나의 전투 엔진으로 설계했습니다.
- **Reinforcement Learning:** C++ 전투 코어에 상태 인코딩, Q-table, 탐험 정책, reward 기반 Q-update를 구현하고 플레이어 패턴 예측과 결합했습니다.
- **Cross-platform Iteration:** 동일한 핵심 전투 아이디어를 C++, Python, JavaScript, Swift로 반복 검증한 뒤 iOS 게임으로 통합했습니다.
- **Quality:** 전투 수치, 조합, 회피, 카운터, AI 적응과 카메라 동작을 회귀 테스트로 검증합니다.

**Architecture:** `Player Input → Combat Engine → Habit Memory → Pattern Snapshot → Adaptive Weights → NPC Decision`

**What this proves:** Reinforcement Learning과 플레이어 모델링을 게임 규칙, 실시간 전투, 3D 표현 및 모바일 UX에 연결할 수 있습니다.

### 2. [STACK112 — AI_SYS](https://github.com/acertainromance401/STACK112)

[![Repository](https://img.shields.io/badge/Source-STACK112-181717?style=flat-square&logo=github)](https://github.com/acertainromance401/STACK112)
[![App Store](https://img.shields.io/badge/Download-App_Store-0D96F6?style=flat-square&logo=appstore&logoColor=white)](https://apps.apple.com/kr/app/stack112/id6768943423)
![SwiftUI](https://img.shields.io/badge/SwiftUI-iOS_17-0D96F6?style=flat-square&logo=swift&logoColor=white)
![LLM](https://img.shields.io/badge/LLM-On--device_Llama-FF6F00?style=flat-square)
![RAG](https://img.shields.io/badge/Search-RAG_%26_IR-1565C0?style=flat-square)

경찰 공무원 시험 준비를 위해 판례를 검색하고, 요약하고, 문제로 학습하는 iOS 애플리케이션입니다. **OCR → Information Retrieval → RAG Evidence → On-device LLM → OX Quiz → Review**로 이어지는 실제 학습 흐름을 구현했습니다.

- **On-device AI:** LlamaSwift(llama.cpp) 기반 로컬 LLM과 rule-based fallback을 구성해 네트워크 없이 요약과 OX 문제를 생성합니다.
- **NLP / IR:** Apple `NLTagger`, 법률 용어 사전, 키워드·핵심 문장 추출, TF-IDF 및 `NLEmbedding` 유사도 검색을 결합했습니다.
- **Grounded Generation:** 검색 근거를 구조화된 프롬프트에 넣고 결과 파싱과 fallback을 적용해 판례 기반 응답의 안정성을 높였습니다.
- **Product Flow:** Vision OCR, 판례 검색·상세, AI 요약, OX 퀴즈, 오답 노트, 약점 분석을 SwiftUI와 SwiftData로 연결했습니다.
- **System Experience:** 온디바이스 우선 구조와 함께 FastAPI, PostgreSQL/pgvector, Docker 기반 백엔드 경로도 설계·구현했습니다.
- **Release:** iPhone 12 mini에서 전체 E2E 흐름과 Release 빌드를 검증하고 App Store 배포까지 완료했습니다.

**Architecture:** `Vision OCR → Local IR / Search → RAG Evidence → Llama.cpp → Summary & Quiz → SwiftData Review`

**What this proves:** NLP·LLM·RAG 기술을 데모 수준이 아닌 완결된 모바일 학습 서비스로 통합할 수 있습니다.

### 3. [SentiVision](https://github.com/acertainromance401/SentiVision)

[![Repository](https://img.shields.io/badge/Source-SentiVision-181717?style=flat-square&logo=github)](https://github.com/acertainromance401/SentiVision)
[![Portfolio](https://img.shields.io/badge/View-Detailed_Portfolio-00695C?style=flat-square&logo=readthedocs&logoColor=white)](https://github.com/acertainromance401/SentiVision/blob/main/Project_Descriptions/SentiVision_Portfolio.md)
![Python](https://img.shields.io/badge/Python-ML_Pipeline-3776AB?style=flat-square&logo=python&logoColor=white)
![iPad](https://img.shields.io/badge/iPad-On--device_AI-000000?style=flat-square&logo=apple&logoColor=white)

사용자가 iPad에서 그린 작품의 색상 특징을 분석해 감정의 결을 해석하고 전시 카드로 보관하는 Affective Computing 프로젝트입니다. **데이터·모델 검증, 온디바이스 분석, iPad 제품 경험, 운영 프로토타입**을 목적별 트랙으로 분리해 구축했습니다.

- **Computer Vision:** 이미지의 전경·saliency 영역을 추출하고 K-Means로 대표 색상 3개를 계산합니다.
- **Machine Learning:** 색상-감정 CSV를 기반으로 KNN을 학습하고 Random Forest와 성능을 비교하며 데이터셋 버전을 관리합니다.
- **On-device Product:** SwiftUI, PencilKit, SceneKit으로 드로잉, 로컬 분석, 감정 패밀리 집계, 3D RGB 분포, 전시형 결과와 아카이브를 구현했습니다.
- **Feedback Loop:** 사용자 피드백을 데이터 보정 후보로 수집해 모델·데이터 개선으로 돌아가는 구조를 설계했습니다.
- **DevOps:** Node 분석 API, Docker, GitHub Actions, AWS ECS 배포 실험, 메트릭과 롤백 자산을 구성했습니다.

**Pipeline:** `Drawing / Image → Foreground Extraction → K-Means Colors → KNN Emotion Mapping → Exhibition & Archive`

**What this proves:** 데이터 전처리와 ML 실험에서 멈추지 않고 분석 결과를 모바일 제품과 배포·운영 환경까지 연결할 수 있습니다.

### 4. [Trend — WAVY](https://github.com/acertainromance401/Trend)

[![Repository](https://img.shields.io/badge/Source-Trend-181717?style=flat-square&logo=github)](https://github.com/acertainromance401/Trend)
![Swift](https://img.shields.io/badge/Swift-iOS-F05138?style=flat-square&logo=swift&logoColor=white)
![CloudKit](https://img.shields.io/badge/Backend-CloudKit-0288D1?style=flat-square&logo=icloud&logoColor=white)
![Status](https://img.shields.io/badge/Stage-MVP-2E7D32?style=flat-square)

사용자가 하루에 하나의 관심 키워드를 제출하고, 참여자들이 직접 만든 오늘의 순위와 변화를 확인하는 iOS 서비스입니다. 입력을 단순 검색어가 아닌 한 표의 데이터로 정의하고, 제출부터 집계·랭킹까지 전체 서비스 규칙을 구현했습니다.

- **Service Rule:** iCloud 사용자 식별자를 이용해 앱 재설치 후에도 하루 1회 제출 제한을 검증합니다.
- **Data Processing:** 공백·대소문자·Unicode NFC를 보수적으로 정규화하고 의미가 다른 키워드의 과도한 병합을 방지합니다.
- **Ranking:** CloudKit Public Database의 오늘·어제 집계를 비교해 현재 순위와 `UP / DOWN / SAME / NEW` 변화를 계산합니다.
- **Concurrency:** 동시 제출 시 CloudKit record conflict를 감지하고 optimistic retry로 집계 정확성을 보완합니다.
- **Product Readiness:** 콘텐츠 필터, 개인정보 보호 문서, 다국어 UI, AdMob과 App Store 등록 자료까지 서비스 출시 관점에서 구성했습니다.

**Data Flow:** `Daily Input → Validation & Normalization → CloudKit Aggregation → Ranking → Trend Change UI`

**What this proves:** 사용자 입력, 데이터 무결성, 순위 로직과 모바일 UX를 실제 서비스 제약 안에서 설계할 수 있습니다.
